## 🛠️ Tech Stack & Philosophy
- **Markup:** Semantic HTML5 (`<header>`, `<nav>`, `<section>`, `<article>`, `<table>`, `<form>`, `<footer>`)
- **Styling:** Modern CSS3, CSS Flexbox, CSS Grid, Polygon Clip-Paths, Tailwind Utility Styling
- **Typography:** Modern, sharp Inter sans-serif pairing
- **Physics:** Canvas 2D spring-damping fluid solver with inertia tracking
- **Constraint Compliance:** Pure HTML/CSS layout architecture suitable for Term 1 grading without unnecessary layout JS.

## 🎓 Evaluation & TA Defense Talking Points

1. **Flagship SaaS Architecture (JEE MockLab):**
   - Full-stack production application built and deployed on Google Cloud Run.
   - Converts real coaching test PDFs into authentic NTA computer-based exam simulators with KaTeX LaTeX rendering and real-time response analytics.
2. **Why Flexbox Quest is built strictly with Flexbox:**
   - Demonstrates command over `flex-direction`, `justify-content: space-between`, `align-items: center`, `flex-wrap: wrap`, and `flex-grow` without relying on Grid or table hacks.
3. **Why Student Portal uses complex HTML tables:**
   - Demonstrates mastery of accessible tabular structures, explicit `<thead>`/`<tbody>`/`<tfoot>`, cell merging via `rowspan` and `colspan`, and responsive table containers.
