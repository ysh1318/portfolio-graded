## 🛠️ Tech Stack & Philosophy
- **Markup:** Semantic HTML5 (`<header>`, `<nav>`, `<section>`, `<article>`, `<table>`, `<form>`, `<footer>`)
- **Styling:** Modern CSS3, CSS Flexbox, CSS Grid, Polygon Clip-Paths, Tailwind Utility Styling
- **Constraint Compliance:** Pure HTML/CSS architecture suitable for Term 1 grading without unnecessary JavaScript overhead for layouts.

---

## 🎓 Evaluation & TA Defense Talking Points

1. **Why Flexbox Quest is built strictly with Flexbox:**
   - Demonstrates command over `flex-direction`, `justify-content: space-between`, `align-items: center`, `flex-wrap: wrap`, and `flex-grow` without relying on Grid or table hacks.
2. **Why Student Portal uses complex HTML tables:**
   - Demonstrates mastery of accessible tabular structures, explicit `<thead>`/`<tbody>`/`<tfoot>`, cell merging via `rowspan` and `colspan`, and responsive table containers.
3. **Architecture of the Portfolio:**
   - High visual aesthetic maintained through geometric `clip-path` math, custom radial gradients, and responsive card layouts.
